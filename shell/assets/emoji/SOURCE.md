# Emoji catalog source

`catalog.json` is a compact derivative of GitHub's
[`gemoji` catalog](https://github.com/github/gemoji/blob/0eca75db9301421efc8710baf7a7576793ae452a/db/emoji.json)
at commit `0eca75db9301421efc8710baf7a7576793ae452a`.

Each entry keeps the emoji (`e`), its joined description, aliases, and tags
(`k`), and its category (`c`). The source catalog intentionally excludes
skin-tone expansions. GitHub's MIT license is preserved beside this file.
